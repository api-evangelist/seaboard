# Seaboard Corporation

> Seaboard Corporation (NYSE American: SEB) is a diversified global agribusiness and
> transportation holding company headquartered in Merriam, Kansas. It publishes NO public
> developer API, NO OpenAPI or other machine-readable contract, and NO developer portal.
> Its only documented machine-to-machine integration surface is the Seaboard Marine
> Electronic Data Interchange (EDI) program.

This file was GENERATED by API Evangelist from probed evidence on 2026-09-04. Seaboard does
not publish an llms.txt of its own; /llms.txt returned 404 on seaboardcorp.com,
seaboardmarine.com and seaboardfoods.com. Nothing below is inferred — every claim traces to a
URL that was fetched, and the absences are absences that were tested for.

## What an agent can and cannot do here

- There is no API to call. No REST, no GraphQL, no gRPC, no SOAP/WSDL, no MCP server, and no
  A2A agent card. `/.well-known/agent-card.json` and `/.well-known/agent.json` were probed on
  all four known hosts and returned 404 or a login redirect.
- Integration with Seaboard Marine is by batch EDI over a bilateral trading-partner
  agreement, arranged by a human through a request form. It is not self-service and it is not
  callable.
- The MySeaboard customer portal is a session-authenticated web application. Every path
  probed on it, including /robots.txt, returns 302 to a login. Treat it as closed.

## Integration surface — Seaboard Marine EDI

- EDI capability catalog: https://www.seaboardmarine.com/services/electronic-data-interchange/
- EDI request form (five steps, trading-partner onboarding): https://www.seaboardmarine.com/edi-request/
- Trading-partner identifiers, published on the request form: ISA qualifier ZZ, sender ID
  DPSCM, SCAC code SMLU.

ANSI ASC X12 transaction sets Seaboard Marine states it exchanges:
204 Motor Carrier Load Tender; 214 Transportation Carrier Shipment Status; 300 Booking
Request; 301 Booking Confirmation; 304 Ocean Shipping Instructions; 309 Manifest data and US
Customs AMS; 310 Bill of Lading data and Ocean Invoice; 315 Shipment Status; 322 Terminal
Operations and Intermodal Ramp Activity; 323 Vessel Schedule and Itinerary; 990 Response to a
Load Tender; 997 Functional Acknowledgement.

UN/EDIFACT messages Seaboard Marine states it exchanges:
COARRI, CODECO, COPRAR, COREOR, CUSCAR, CUSRES, BAPLIE, VERMAS, APERAK.

Seaboard Marine does NOT reference the DCSA track-and-trace or booking API standards that
larger ocean carriers have adopted. If you need a callable container-tracking API, this
carrier does not have one.
